# VB.NET Linear Algebraic Project

This repository contains a VB.NET Visual Studio project implementing 25 Linear Algebraic Mapping Problems (LAMP). Its compiled DLL can be supplied as input to AD.Net to generate tangent and adjoint assemblies.

## Download Contents

The `vbLinearAlgebraicProject.rar` archive contains:

- The complete VB.NET Visual Studio project
- Source code implementing the 25 LAMP equations
- An already compiled DLL alongside the project
- Another compiled copy inside the project's `bin` directory
- The project files required to rebuild the assembly

Users can upload the included DLL directly to AD.Net without rebuilding the project. The source project is also included for users who want to inspect, modify, or recompile the equations.

## Requirements

The following software and libraries are required only when rebuilding the project:

- Visual Studio 2022 or a compatible version
- The .NET target framework specified in the project file
- MathNet.Numerics

Visual Studio should restore the required NuGet packages automatically when the solution is opened.

AD.Net is required when generating differentiated assemblies from the compiled DLL.

## Using the Precompiled DLL with AD.Net

1. Download `vbLinearAlgebraicProject.rar`.
2. Extract the archive.
3. Locate the included `vbLinearAlgebraicProject.dll`.
4. Open the [AD.Net interface](http://ad_net.stce.rwth-aachen.de).
5. Upload the DLL.
6. Select the method or methods to differentiate.
7. Select tangent or adjoint mode.
8. Run the transformation.
9. Download the differentiated assembly generated by AD.Net.

The included DLL is already compiled, so rebuilding the Visual Studio project is not required before using it with AD.Net.

## Rebuilding the Project

Users who want to inspect, modify, or rebuild the assembly can:

1. Extract `vbLinearAlgebraicProject.rar`.
2. Open the solution (`.sln`) in Visual Studio.
3. Allow Visual Studio to restore the required NuGet packages.
4. Select `Release` as the build configuration.
5. Select **Build > Build Solution**.

The rebuilt DLL will normally be created inside the `bin/Release` directory or its framework-specific subdirectory.

## Differentiation Outputs

The project and AD.Net workflow provide three forms of the supported computations:

- **Standard (primal):** the original implementation of each LAMP equation
- **Tangent:** the forward-mode derivative implementation generated by AD.Net
- **Adjoint:** the reverse-mode derivative implementation generated by AD.Net

AD.Net creates new differentiated assemblies and does not overwrite the original input DLL.

## LAMP Equations

The project contains 25 Linear Algebraic Mapping Problem equations from applications including:

- Least-squares estimation
- Matrix equations and inversion
- Optimisation
- Filtering
- Regularisation

The implementations use matrix and vector operations from `MathNet.Numerics.LinearAlgebra`.

## Other Language Versions

Corresponding implementations of the 25 LAMP equations are also available in:

- [C#](https://github.com/ad-dotnet/CSharpLinearAlgebraicProject)
- [F#](https://github.com/ad-dotnet/FSharpLinearAlgebraicProject)

Because AD.Net operates on compiled Microsoft Intermediate Language (MSIL), assemblies produced from C#, VB.NET, and F# can be processed using the same transformation approach.
